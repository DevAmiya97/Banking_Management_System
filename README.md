# Banking_Management_System

Banking Management System
A console-based Banking Management System built using Java, JDBC, PostgreSQL, and Maven.

Features

User Registration & Login
Bank Account Creation
Credit Money
Debit Money
Fund Transfer
Balance Inquiry
Transaction History
JDBC PreparedStatement
Transaction Management (Commit/Rollback)

Tech Stack
Java
JDBC
PostgreSQL
Maven
OOP

Project Structure
User.java
Accounts.java
AccountManager.java
TransactionHistory.java
BankDriver.java
